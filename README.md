# Prageeth Gunarathne - Portfolio

A premium modern personal portfolio built with **Next.js App Router**, **TypeScript**, **Tailwind CSS**, **Framer Motion**, and **lucide-react**.

## Tech Stack
- Next.js 14 (App Router)
- TypeScript
- Tailwind CSS
- Framer Motion
- lucide-react
- react-icons

## Features
- Premium dark tech UI with Sera Blue theme
- Responsive design (mobile/tablet/desktop)
- Animated hero and smooth section transitions
- Skills, experience timeline, project showcase, education, and contact form
- WhatsApp, GitHub, LinkedIn, and email quick actions
- SEO metadata configured in `app/layout.tsx`

## Project Structure
- `app/` - App Router pages and global styles
- `components/` - Reusable UI sections
- `data/portfolio.ts` - Portfolio content and typed data model
- `public/` - Static assets and project images

## Getting Started
Install dependencies:

```bash
npm install
```

Run development server:

```bash
npm run dev
```

Open `http://localhost:3000`.

## Build for Production
```bash
npm run build
npm run start
```

## Lint
```bash
npm run lint
```

## Customization
Edit content in:
- `data/portfolio.ts`

Update styles in:
- `app/globals.css`
- `tailwind.config.js`
